# 트렌드 자료 입력 템플릿

이 파일을 채워서 `--trend <이 파일 경로>` 로 넘기면 `TREND_ANALYST` 가 분석한다.

## 채우는 원칙 (중요)

**남의 작품 본문을 붙여넣지 마라.** 필요 없고, 위험하다.

시스템이 필요로 하는 건 **경향을 읽을 수 있는 사실 정보**다.
"이번 달 상위 30편 중 18편이 회귀 소재" 같은 **관찰과 통계**는 사실이고,
사실에는 저작권이 없다. 반면 남의 소개글·본문을 그대로 옮겨 저장하는 것은 복제다.

수집할 때 각 플랫폼의 이용약관과 `robots.txt` 를 확인하고, 자동 크롤링 대신
**직접 보고 손으로 옮겨 적는 방식**을 기본으로 삼아라. 상업적 이용이 걸려 있다면
정확한 판단은 변호사에게 확인하는 것이 맞다.

---

## 1. 관측 기준

- 수집일:
- 플랫폼:
- 범위: (예: 판타지 장르 실시간 랭킹 1~50위)

## 2. 순위 목록 — 제목과 태그만

| 순위 | 제목 | 장르 태그 | 회차 수 | 연재 주기 |
|---|---|---|---|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

> 제목은 짧은 단어 조합이라 일반적으로 저작물성이 인정되지 않는다. 목록화해도 무방하다.
> **소개글·본문은 옮기지 마라.** 읽고 나서 아래 "직접 관찰" 칸에 네 말로 요약하라.

## 3. 직접 관찰 (네 문장으로)

소재 분포:
> 예) 50편 중 회귀 21, 헌터/게이트 12, 아카데미 8, 영지경영 5, 기타 4

제목 짓는 패턴:
> 예) "[숫자]회차", "몰락한 [신분]", "[직업]인데 [반전]" 형태가 반복됨

1화에서 공통으로 하는 것:
> 예) 대부분 첫 화 절반 안에 주인공이 능력을 실제로 사용한다. 설명으로 여는 작품은 상위권에 거의 없음

최근 줄어든 것:
> 예) 순수 학원물, 느린 성장물

의외였던 것:
> 예) 상위권에 완결작이 다수. 연재 중이 아니어도 유입이 있음

## 4. 내가 노리는 자리

> 예) 회귀는 포화 상태지만 "되돌아와서 아무것도 안 바꾸려는 주인공" 은 못 봤다. 그 자리를 노린다.

---

## 자료 없이 돌리려면

```bash
node src/cli.js run --idea "..." --trend auto
```

모델 내재 지식으로 추정하고, 결과의 `knowledge_cutoff_warning` 에
**추정임이 명시**된다. 실행 요약에도 에스컬레이션으로 기록되므로 그대로 믿지 말 것.
